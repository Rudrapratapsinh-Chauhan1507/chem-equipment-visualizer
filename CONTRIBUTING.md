# Contributing Guide

Welcome to the Chemical Equipment Parameter Visualizer project! Please review these guidelines for contributing code, documentation, or ideas.

## How to Contribute

1. **Fork and Clone Repository**
   - Fork the repo on GitHub and clone your copy for local development.

2. **Branching Workflow**
   - Create feature branches from `main` (e.g., `feature/backend-init`, `feature/react-setup`).
   - Work in your branch; do not commit directly to `main`.

3. **Commits & Pull Requests**
   - Write clear, concise commit messages.
   - Submit pull requests for all changes; assign reviewers when possible.
   - Address feedback and follow code review suggestions.

4. **Code Standards**
   - Backend: Follow PEP8 for Python; use Django best practices.
   - Web: Use consistent React folder/component naming; use hooks/function components.
   - Desktop: Structure PyQt5 code into main script plus modules (as needed).
   - Include comments for clarity when logic is complex.

5. **Testing**
   - Test your code before submitting PRs.
   - Ensure backend runs locally, web and desktop interfaces start successfully.

6. **Documentation**
   - Update README or relevant docs if usage/setup changes.
   - Add docstrings or code comments for new functions or modules.

## Reporting Issues

- Use GitHub Issues to report bugs or suggest features.
- Provide steps to reproduce problems when filing bugs.

## Communication

- Use GitHub Discussions or pull request comments for team coordination.
- For urgent issues, mention @team-leaders.

Thank you for contributing!
