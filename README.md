# Chemical Equipment Parameter Visualizer

This project delivers a hybrid solution for chemical equipment data analytics, providing both web and desktop applications connected to a unified Django backend API.

## Features (Milestone 1)
- Organized repository structure for backend, web, and desktop frontends
- Clearly defined tech stack:
  - **Backend**: Django, Django REST Framework, Pandas, SQLite
  - **Web**: React.js, Chart.js
  - **Desktop**: PyQt5, Matplotlib
- Version control and collaboration via GitHub
- Project planning and contribution guidelines

## Tech Stack
| Layer              | Technology                |
|--------------------|--------------------------|
| Backend            | Django, DRF, Pandas, SQLite|
| Web Frontend       | React.js, Chart.js        |
| Desktop Frontend   | PyQt5, Matplotlib         |
| Version Control    | Git, GitHub               |
